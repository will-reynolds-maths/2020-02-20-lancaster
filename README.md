# CoDiMa Software Carpentry workshop, Lancaster, 20-21 February 2020
https://ccp-codima.github.io/2020-02-20-lancaster/

This repository is a fork of a workshop exercise used during a GitHub training session in 2020. The workshop organisers imported a template repository and provided it for participants to explore GitHub functionality. The template was The Carpentries' template for creating websites for workshops.

I participated in the workshop and forked their version as instructed. This repository is no longer maintained.
